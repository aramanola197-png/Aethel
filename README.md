# Aethel Website

Professional static multi-page website for Aethel Automotive Influencer Agency.

## Structure
- index.html — Homepage
- about.html
- talent.html
- talent-profile.html (sample profile template)
- work-with-us.html
- contact.html
- enquire.html
- privacy.html
- css/style.css
- js/main.js
- images/ — placeholder images

## Notes
- Dark charcoal theme with racing red accent.
- Fully responsive.
- Sticky header with Enquire Now button (opens modal).
- Forms currently show a thank-you alert (replace with Formspree, Netlify Forms, or backend for production).
- All talent, logos, and testimonials are placeholders — replace with real content.
- No fake statistics or clients invented.

## Deployment
1. Extract and push to a GitHub repository.
2. Import the repo into Vercel.
3. After deployment, add your custom domain in the Vercel project Settings → Domains.
4. Update DNS records at your domain registrar as instructed by Vercel.
